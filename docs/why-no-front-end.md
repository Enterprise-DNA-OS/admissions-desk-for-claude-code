# Why no front end

The admissions coordinator asks about missing documents, reader queues and unanswered offers. One database answers those questions. The coding agent runs the commands and prepares a private weekly review.

npm run view generates a read-only weekly report. npm run docs generates committee packets, decision evidence records and missing-material checklists. Change the business name, logo and colours in brand.json. These are static reports, not interactive application screens.

Slate also has applicant portals, online forms, document reading, communications and wider student lifecycle functions. This base does not collect applications, display documents beside scoring forms, send official decisions, handle payments or offer mobile and offline work. Keep those services until a custom version provides what your institution requires. Enterprise DNA can scope the forms, connections and screens around your actual process.

The database is the owned record. Claude Code, Codex, OpenCode or Cursor is the operator's door. /new-view adds read-only analysis and /customise adds a tested field or rule without a second command library.
